## 2. 與本專案差異（描述，不評對錯）

1. **缺值**：四者在所讀範圍皆為「預設值或丟棄」；本專案已保留空受詞事實。三態標示（Wikibase 式，見 README G-A）在這些專案中**查無**實作。
2. **身份**：多為「名稱（＋類型）」；只有 Graphiti 有識別碼並**把合併寫成圖中的邊**。本專案的合併紀錄是否可追溯，不在本檔判斷。
3. **失效**：僅 Graphiti 有；且是**時間戳＋矛盾偵測**。**G-C 結論**：在所讀程式碼中，**沒有任何一個專案把關係做成顯式狀態機**，也沒有「僅由條件／事件、不經時間」觸發失效的實作——與使用者設計無直接對應物。
4. **來源**：都有某種來源指標；LightRAG 用 `"unknown_source"` 佔位字串，與「未知」未區分於其他情況。
