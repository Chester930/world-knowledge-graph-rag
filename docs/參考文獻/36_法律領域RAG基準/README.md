## 角色與已查證內容

摘要（2026-09-21 WebFetch 查證）：基準含 6,858 組由法律專家標註的問答對，語料超過 7,900 萬字元；重點是**檢索最小、最相關的文字片段**而非整份文件或大區塊，理由是長上下文成本高、延遲高，並讓 LLM 更容易遺忘或幻覺。

**對本專案的意義（含風險）**：這篇支持「法規問答的檢索品質應以片段層級的精準度衡量」，與報告57 §2 的 Context Recall／SNR 方向一致。但它同時是一個**反向提醒**：報告57 §4.21 提出的「條文層級擴充」（撈到某條文任一 Fact 就帶入同條文兄弟 Fact）會加大上下文，可能違背「最小精準片段」的原則、拉低 SNR，實驗時必須同時量 SNR。

**誠實侷限**：這是英文基準（我沒有核對其語料涵蓋的法域），不是中文法規，也不是知識圖譜方法；只能佐證評測原則，不能佐證 KG 的效果。
