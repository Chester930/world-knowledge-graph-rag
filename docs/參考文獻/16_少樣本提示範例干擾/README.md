# 16_少樣本提示範例干擾

對應 `../../論文/03_系統設計與方法論.md` § 3.1.3（SVO 抽取 prompt 設計）；`../../論文/03_變更紀錄.md` 2026-08-28「規則7範例相似度導致 LLM 抄錯範例名詞；340 筆批次重抽取完成」條目。

## 起點：真實資料重跑才發現的失效案例

2026-08-28，`services/svo_service.py::_svo_prompt()` 規則 7（同句多筆事實）原有一個範例（`事假期間, 不給, 工資`），本次新增另一個結構高度相似的反例範例（原寫 `婚假期間, 照給, 工資`）。真實 pipeline 重跑婚假 chunk 時，LLM 把第三筆三元組的 subject 抽成「事假期間」——不是輸入文本裡的內容，而是**抄了鄰近範例的主詞**。

## 內容清單

| 檔案 | 文獻 | 來源 |
|---|---|---|
| `ali-wolf-titov-2026-copy-bias-icl.pdf` | Ali, Wolf & Titov (2026), *Mitigating Copy Bias in In-Context Learning through Neuron Pruning*，Findings of EACL 2026, pp. 230-251 | arXiv:2410.01288 |

**查證結果**：這篇論文明確命名並研究「copying bias」——LLM 在少樣本 ICL 中傾向直接複製提供範例裡的答案，而非從實際輸入學習底層規律，與本次真實踩到的失效模式（抄範例主詞而非讀輸入文本）完全對應。論文本身的解法是神經元層級的剪枝（訓練後介入模型內部），與本論文採用的 prompt 層級修正（降低範例間表面相似度＋新增一句明確禁止照抄的指示）是不同的技術路線——論文佐證的是**現象本身確實存在且是已知的研究問題**，不是本論文修正方法的技術依據。

## 誠實聲明

- 這是一個實作過程中發現的具體案例，範圍侷限於「本次規則 7 範例設計」，不是本論文提出的通用理論貢獻。
- 未查證是否有 prompt-only（不訓練介入）層級的複製偏誤緩解文獻——目前的修正（降低範例相似度＋明確禁止指示）是依常識設計並以真實資料驗證有效，未額外查證是否有對應學術文獻支持這個具體修正手法本身。
