# 文獻與專案查核表

本表將「文獻存在」「本機已有檔案」「全文已精讀」「官方程式碼存在」「本專案是否實際採用」分開記錄，避免把本機檔案或搜尋結果誤寫成已完成驗證。

## 查核狀態定義

| 狀態 | 意義 |
|---|---|
| ✅ 存在 | 可由出版社、正式會議頁、arXiv 或作者／組織官方頁面確認存在 |
| 📥 已下載 | 本機參考文獻資料夾有對應 PDF；不代表已完成全文精讀 |
| 📖 已精讀 | 已逐段閱讀並確認本文引用的具體方法或結果 |
| 🔗 官方程式碼 | 可由論文頁面或作者／組織官方帳號連到公開 repository |
| 🧩 本專案採用 | 本專案實際使用該專案程式碼或演算法；僅作設計參考時不可標記此欄 |
