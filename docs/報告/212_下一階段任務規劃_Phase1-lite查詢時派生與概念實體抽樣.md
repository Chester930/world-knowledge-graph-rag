## 3. 各任務規格

### L1：「概念」實體抽樣

**目標**：回答「8,023 個型別為『概念』的實體，有多少其實是『未標型別的佔位』、有多少確為抽象概念？」，作為使用者日後決定 A／B 的證據。
**防護（與報告195 F2／199 H1／207 K2 完全相同，缺一不可，違反即停止）**：

1. 開始前確認無他 session 在用同一 Neo4j／Ollama（Claude 執行對話用 `ListAgents`；Codex 若無此介面，**明寫無法確認並請使用者確認**）。
2. 使用既有 `kg2-neo4j` 容器（`bolt://localhost:17990`）。**KG#4（`236903cf`）是唯一副本，絕對不得 wipe／清空／重建／寫入。**密碼在 `kg-reextract/.env`，**不得印出或寫入任何檔案**。
3. **只執行唯讀 Cypher**；`default_access_mode=READ`；**重用** `scripts/analysis/semantic_layer_invariants.py` 的 `assert_read_only()`／`ReadOnlyRunner`，**不得放寬**。
4. **不啟動 Ollama／WSL 模型、不呼叫任何 LLM／embedding。**
5. 前後各查總節點／總關係／Fact／Entity，**須為 57,451／137,873／16,826／12,296**，寫入報告。
**做法**：

1. 母體＝`type` **精確等於**「概念」的 Entity（預期 8,023）。以**固定種子**（寫明種子與抽法）抽 **50 個**。
2. 每個實體材料：名稱、度數（連幾條關係）、它所在的 1–2 條事實（作主詞或受詞）與其**來源原句逐字**（沿用報告200 的 chunk＋子字串取原句法；`source_sentence_start/end` 是 chunk 內相對範圍）。
3. **草稿標註**（執行者先標，使用者之後確認）：
   - `P`＝**佔位**：名稱其實有更合適的 schema.org 標準型別（如人／組織／地點／事件／法規文件等）——請附**建議型別**；
   - `C`＝**確為抽象概念**：制度、規定、狀態、數量、行為等，schema.org 無明顯更合適型別；
   - `U`＝無法判斷。
   並附一句理由與「疑問」旗標（疑問筆置前；占比如實寫）。**標註標準寫明**，且**草稿一律標「未經使用者確認」**。
4. 輸出使用者友善審閱檔（使用者只回「第 N 筆改成 X」）＋可重算 CSV；統計用既有 Wilson 腳本（`scripts/analysis/empty_object_annotation_stats.py` 若可泛用則重用，否則新增極小腳本並附測試）。
**驗收**：原句逐字可在 `original.md` 找到（我會抽查）；抽樣可重現（種子＋抽法）；疑問占比如實；Cypher 全唯讀、前後總數相同；全量 pytest ≥1613 passed、0 failed；腳本匯入不得改 `os.environ`（有測試）。

### L2：派生函式庫（不接線）

**目標**：把「三種標示」的**查詢時派生規則**寫成純函式，使 Phase 0 的人工計算可由程式重現，並為日後接進檢索／回答做準備；**本階段不接線**。
**要求**：

1. **位置**：新增純 Python 模組（建議 `services/semantic_marks.py`，位置由執行者依專案架構與節點卡規範決定並說明理由）。**純運算、無 I/O、不匯入 `neo4j`／`core.config`／`routers`／`services` 其他重量模組**；匯入不改 `os.environ`（有測試）。
2. **標示值域（暫定，標 `PROVISIONAL`，列常數）**：已解決、不適用、未知、尚未處理、無法由現有資料判定。**不得使用哨兵字串寫回任何資料**；這些只是函式回傳值。
3. **函式（至少）**：
   - 實體型別 → 標示。參數 `concept_scheme`：`"A"`（「概念」視為未知佔位，**預設**）、`"B"`（視為已解決）、`"strict"`（無法判定）；空值、標準型別（核心 52／擴充 939，沿用 `services/extraction/prompt.py` 的查表邏輯但**不得改動它**）、schema.org 之外原字串各有明確對應；
   - 關係型別 → 標示：非 `RELATED_TO`＝已解決；`RELATED_TO`＝**來源不明**（對應「無法由現有資料判定」；使用者已同意接受）；**不得**以 `verb_embedding` 的有無推論來源（報告201 讀碼確認它不是兜底專屬標記）；
   - `source_article_no` → 標示：由**文件層**是否有條號判斷（已知／不適用／未知）；**不得使用哨兵字串、不得依賴空字串／`None` 的真假值直接當標示**；
   - 空主詞／空受詞／空 `verb` → 標示：沿用報告209 的嚴格規則（空受詞且空 `verb`＝未知〔145〕；其餘至少一空者＝尚未處理〔5,136〕；完整＝已解決）。
4. **測試**：每個函式、每個分支、每個參數值（含三種 `concept_scheme`）都有單元測試；含**邊界案例**（空白字串、`None`、逗號多值型別、大小寫／底線變體）；**不連 Neo4j**。
5. **零行為變更的證據**：以 `Grep` 證明**沒有任何現有 `.py` 匯入或呼叫此模組**（除測試與 L3 腳本）；`check_node_cards.py`（警告模式）**不得新增警告**，若有請說明；全量 pytest ≥1613 passed。
**禁止**：接進 `chat()`、`merge_*`、`extract_*`、檢索或任何現有路徑；改動任何既有函式；新增儲存欄位；替使用者決定欄位名／值域（保持 `PROVISIONAL`）。
