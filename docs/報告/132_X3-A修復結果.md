
### 5.2 `update_status` 缺失列

`services/task_queue_service.py:34-45` 新增只在 `update_status` 內使用的 rowcount tracking proxy；`update_status` 在 `:116` 先包住既有 connection，既有 `conn.execute(...)` SQL 行完全保留，`commit()` 後於 `:123-131` 只讀取執行結果的 `rowcount`。rowcount 為 0 時才新增一則 WARNING；函式仍無 `return`，因此仍回傳 `None`。

為了同時保留原有 SQL 呼叫行與 `git diff` 的 additions-only 約束，proxy 只轉送既有 `execute`、`commit`、`close` 等操作並記住該次 cursor；沒有新增 SQL。狀態參數若為 `StateTaskStatus`，日誌取 `.value`，所以輸出 `completed`，不會輸出 `TaskStatus.COMPLETED`。

日誌格式固定為：

```text
[TaskQueue] update_status：查無對應列，狀態更新被略過（kg_id=<kg_id> source=<source> chunk_index=<chunk_index> status=<字面值>）
```
