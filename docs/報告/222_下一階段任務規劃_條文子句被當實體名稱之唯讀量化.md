## 1. 要回答的問題（使用者看得懂的版本）

圖譜裡有些「實體」的名字其實是一整句條文，例如「勞工在同一雇主繼續工作滿五年以上十年未滿者」。這種實體很難跟別的事實接起來（名字太長、全圖只出現一兩次），可能影響檢索。我們不知道這種情況有**多普遍**、**集中在哪些型別**、**有多少事實受牽連**。本階段只回答這三件事，不修。

- **「像子句」的操作型定義（暫定，需在報告明寫並以參數表示，可調）**：以**長度門檻**（建議同時報 ≥8／≥12／≥20 字三檔）為主，輔以**特徵**（含「者」「之」「應」「得」「不得」「視為」「以上」「未滿」「其」「前項」等條文用語、含逗號／頓號／括號、含數字加單位）。**不得**用 LLM 判定。明確寫出每個特徵的比對方式與其誤判風險（例如：長名稱不一定是子句，如「勞動基準法施行細則第三十五條」是合法的長名稱）。
- **要輸出**：
  1. Entity 12,296 的名稱長度分布（分位數、直方圖）、各門檻檔的數量與占比；全圖對比「概念」型別與非「概念」型別；
  2. 各門檻檔的**型別分布**（A／B／strict 三種 `concept_scheme` 並列，使用 `services/semantic_marks.py`，不得改動它）；

  4. **受牽連的 Fact 數**（以這些實體當主詞或受詞的 Fact 占 16,826 的比例）；
  5. 與報告218 的已保存檢索結果交叉：被檢索／進 prompt 的 Fact 中，有多少端點是「像子句」實體（沿用 `scripts/analysis/semantic_marks_replay_join.py` 的 join 結果，**不重做 join 邏輯、不新增 DB 查詢**，除非必須；必須時另列並說明）；
  6. 若同一子句在不同文件以微小差異重複出現（近似重複），給出初步計數與判定方式（例如僅比對去除標點與空白後的完全相同，**不做相似度模型**），標示其保守偏差。
- **腳本**：放 `scripts/analysis/`，**純運算（門檻、特徵、彙整）與 DB 存取分離並附單元測試**（假資料）；匯入不得改 `os.environ`（測試）。

### O2 抽樣

- 母體＝**長度 ≥12 字**的 Entity（若與 O1 主門檻不同需說明）；**固定種子**（建議 `20261014`，寫入產物）抽 **50 個**；每個附：名稱、型別、度數、所在文件數、1–2 條事實與**來源原句逐字**（沿用報告200／214 的 chunk＋子字串取原句法，`source_sentence_start/end` 為 chunk 內相對範圍）。
- **草稿判讀**（先標、使用者之後確認、**一律標「未經使用者確認」**）：
  - `S`＝**子句**：名稱是一整句或半句條文，拆成「主體＋條件／行為」更合理；
  - `L`＝**合法長名稱**：法規名稱、機構全名、專有名詞等，長是正常的；
  - `U`＝無法判斷。
  並附一句理由與「疑問」旗標（疑問筆置前，占比如實寫）。輸出**使用者友善審閱檔**（使用者只回「第 N 筆改成 S／L／U」）＋可重算 CSV；統計重用或泛化 `scripts/analysis/concept_entity_annotation_stats.py` 的 Wilson 計算（不改動現有行為，若要泛化須保留舊測試通過）。
- **驗收**：原句逐字可在 `kg-runtime/236903cf-…/<文件夾>/original.md` 找到（我會抽查）；抽樣可重現；疑問占比如實；腳本不印密碼。
