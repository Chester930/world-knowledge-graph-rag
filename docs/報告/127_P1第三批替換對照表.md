## 3. 行為約束逐項判斷（§0 硬性約束 1–3）

### 3.1 公開函式行為、X1、X3

- **保持不變**：公開函式簽章、回傳型別／`None` no-op、ValueError 的既有檢查順序、欄位更新順序、`_write_record()` 時機。
- **X1 成立且保留**：baseline 快照顯示 `mark_extraction_failed()` 後再 `record_chunk_completed(2)`，狀態由 `failed` 變為 `processing`。不得在入口加入 current-state guard，也不得把此格改成 `failed`。
- **X3 成立且保留**：baseline 對缺少 `_record.json` 的 normalization、SVO total、reset、chunk completed、mark failed 五個公開寫入函式均為回傳 `None`、不建立檔案、不拋例外。第二段不可改為 raise 或自動建立。
- `total=0` 的 `record_chunk_completed(1)` 仍因 `total and ...` 為假而寫 `processing`，不是 `completed`。

### 3.2 非法 normalization status 字串：保持現況的具體做法

現況 `update_normalization_progress()` 的公開簽章是 `Literal["not_started", "processing", "completed", "failed"]`，但 Python runtime 不會阻擋呼叫端傳入 `"legacy_invalid"`；函式會完成數字檢查，將該字串寫入 `_record.json`，不在這一行提前 `ValueError`。baseline 已實測：`update_normalization_progress(status="legacy_invalid", progress=4)` 正常回傳並將 raw JSON 的 `normalization_status` 寫成 `legacy_invalid`。

為保持逐字行為，第二段的 `_transition_normalization()` 必須先判斷 target 是否為四個 Enum `.value` 之一：

```python
valid_targets = {item.value for item in NormalizationStatus}
if target not in valid_targets:
    # compatibility branch：不呼叫 NormalizationStatus(target)，不提前失敗。
    record.normalization_status = target
    return
record.normalization_status = normalization_next_status(
    NormalizationStatus(record.normalization_status),
    event,
    NormalizationStatus(target) if target is not None else None,
).value
```

這個 raw compatibility branch 仍位於唯一的 `_transition_normalization()` 賦值入口內；它不是新增驗證，也不是修復非法資料，而是保留現有「可寫入、下次 Pydantic 讀取才可能失敗」的行為。第二段必須新增／執行一個 characterization assertion，確認非法字串呼叫不在 `update_normalization_progress()` 當下拋 `ValueError`，且 raw `_record.json` 內容仍為該字串；不得改公開簽章來放寬型別，也不得把非法值轉成合法 Enum。

### 3.3 JSON 快照相等性

baseline 腳本每個操作後直接讀取 `_record.json` 完整 JSON；所有 `*_at` 時間欄位正規化成 `<normalized-time>`，固定 UUID、固定輸入文字與固定操作順序。第二段應用**同一支腳本**產生 `after_record_snapshots.json`，比較 snapshots／operations 的完整結構；任何非時間欄位差異均停下回報。

"""Offline SM-1/SM-1b characterization for report 126 S2.

The script only exercises document_record_service and ingestion_service against
fresh folders below this temporary directory.  After every public operation it
reads the complete _record.json directly, replacing time-valued fields with a
fixed marker.  It never starts Neo4j, Ollama, a server, an import job, or a
re-extraction job.

Usage:
    python reproduce_record_snapshots.py D:/path/to/repository
    python reproduce_record_snapshots.py D:/path/to/repository after_record_snapshots.json
"""
from __future__ import annotations

import json
import shutil
import sys
from pathlib import Path
from typing import Any, Callable
from uuid import UUID


TIME_MARKER = "<normalized-time>"
KG_A = UUID("00000000-0000-0000-0000-000000000001")
KG_B = UUID("00000000-0000-0000-0000-000000000002")


def normalize_times(value: Any) -> Any:
    if isinstance(value, dict):
        return {
            key: TIME_MARKER if key.endswith("_at") else normalize_times(item)
            for key, item in value.items()
        }
    if isinstance(value, list):
        return [normalize_times(item) for item in value]
    return value


def record_snapshot(folder: Path) -> dict[str, Any] | None:
    path = folder / "_record.json"
    if not path.exists():
        return None
    return normalize_times(json.loads(path.read_text(encoding="utf-8")))


def add_operation(
    scenario: dict[str, Any],
    name: str,
    folder: Path,
    action: Callable[[], object],
) -> object:
    result = action()
    scenario["operations"].append(
        {
            "operation": name,
            "outcome": "returned None" if result is None else f"returned {type(result).__name__}",
            "record": record_snapshot(folder),
        }
    )
    return result


def new_scenario(name: str) -> dict[str, Any]:
    return {"name": name, "operations": []}


def main(repo: Path) -> None:
    sys.path.insert(0, str(repo))
    from services import document_record_service as records
    from services import ingestion_service

    root = Path(__file__).resolve().parent
    run_root = root / "run-data"
    if run_root.exists():
        shutil.rmtree(run_root)
    run_root.mkdir(parents=True, exist_ok=True)

    scenarios: list[dict[str, Any]] = []

    normal = new_scenario("normal_sequence_and_reset")
    scenarios.append(normal)
    normal_folder = run_root / "normal_sequence" / "staging" / "report"

    def stage_document() -> object:
        actual_folder, record = ingestion_service.chunk_and_stage(
            "第一句。第二句。第三句。", "report.txt", normal_folder.parent,
        )
        assert actual_folder == normal_folder
        return (actual_folder, record)

    add_operation(normal, "chunk_and_stage", normal_folder, stage_document)
    add_operation(
        normal,
        "append_assignment(KG-A)",
        normal_folder,
        lambda: records.append_assignment(normal_folder, KG_A, "KG-A", "manual"),
    )
    add_operation(
        normal,
        "set_svo_chunk_total(3)",
        normal_folder,
        lambda: records.set_svo_chunk_total(normal_folder, 3),
    )
    add_operation(
        normal,
        "record_chunk_completed(1)",
        normal_folder,
        lambda: records.record_chunk_completed(normal_folder, 1),
    )
    add_operation(
        normal,
        "record_chunk_completed(2)",
        normal_folder,
        lambda: records.record_chunk_completed(normal_folder, 2),
    )
    add_operation(
        normal,
        "record_chunk_completed(3)",
        normal_folder,

        normal,

        normal_folder,

    x1 = new_scenario("X1_failed_then_other_chunk_completed")
    scenarios.append(x1)
    x1_folder = run_root / "x1" / "document"
    add_operation(
        x1,
        "init_record(total_chunks=3)",
