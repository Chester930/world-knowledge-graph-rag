## 0. 問題與設計（已由 Claude 讀碼確認，不需重新調查）

虛擬歸屬（`ENABLE_VIRTUAL_MANIFEST_ASSIGN=True`）下，`assign_document_to_kg()` 回傳**原文件資料夾**（`services/classify_service.py:615`），文件只存一份。現況三個斷點：

| # | 位置 | 現況 | 後果 |
|---|---|---|---|
| B1 | `services/svo_service.py:3641-3648` | `kg_folder = doc_folder.parent`，同時當 `base_dir` 與 `output_dir` 傳給 `prepare_svo_ready_chunks` | SVO 輸出（`svo_index.json`、chunk、sentence_embeddings）寫進暫存區／中央池，不在 KG 資料夾 |
| B2 | `services/extraction_worker.py:87-89` | 讀 `Path(kg.folder_path)` 底下的 `svo_index.json` | 找不到 → `_find_chunk` 回 None → chunk 標 failed |
| B3 | `services/extraction_worker.py:146-147、161` | `record_chunk_completed(doc_folder…)`／`mark_extraction_failed(doc_folder…)` 的 `doc_folder = document_folder_path(source, kg_folder)` | 虛擬模式下 `kg_folder/<doc>/` 沒有 `_record.json`；這兩個函式在記錄不存在時**靜默回 None**（`document_record_service.py:204-206、218-221`），抽取進度永遠寫不進真正的記錄檔（第二個隱性 bug，報告109 未提到） |
| B4 | `routers/staging.py:95-99` | 自動分支自組 `kg_folders[matched_kg_id] / result.filename` | 虛擬模式下該路徑不存在 |

### 修正設計（契約）

- **輸入位置**（原文、`_record.json`、`sentences.json` 等）＝文件實際所在資料夾 `doc_folder`（即 `assign_document_to_kg` 的回傳值）。
- **SVO 輸出位置**（`svo_index.json` 與其 chunk／embedding 檔）＝`kg_folder / <doc 資料夾名>`，其中 `kg_folder = Path(kg.folder_path)`，與 worker 既有讀取位置一致。
- **記錄檔位置**＝文件實際所在資料夾。worker 以新函式 `resolve_document_folder()` 解出。
- 實體搬移模式（`move_physical=True`）下 `doc_folder` 已在 KG 資料夾內，三者重合，**行為必須與修正前完全相同**。

```python
def resolve_document_folder(kg_folder: Path, doc_id: str) -> Path:
    """解出某文件實際所在的資料夾（報告110）。

    實體搬移模式：文件在 ``kg_folder / doc_id``；虛擬歸屬模式：文件只存一份於
    中央池／暫存區，KG 資料夾僅有 ``_members.json``，實際位置記在 manifest 的
    ``source_path``。兩者皆找不到時回傳 ``kg_folder / doc_id``（呼叫端讀不到
    記錄時的既有降級行為維持不變，不在此拋例外）。
    """
    physical = kg_folder / doc_id
    if physical.is_dir():
        return physical
    manifest = _read_members_manifest(kg_folder)
    for entry in manifest.get("assigned_documents", []):
        if isinstance(entry, dict) and entry.get("doc_id") == doc_id:
            source_path = Path(str(entry.get("source_path", "")))
            if source_path.is_dir():
                return source_path
    return physical
```
