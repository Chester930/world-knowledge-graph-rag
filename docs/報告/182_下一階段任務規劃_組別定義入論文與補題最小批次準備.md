## 3. 各任務規格

### B1：順序相依失敗測試

**問題**：`tests/core/test_embedding_migration.py::test_shipped_embedding_defaults_are_bge_m3_1024_without_env_overrides` 全量跑失敗、單檔跑通過（報告177 Z1 回報）。
**做法**：

1. 重現：全量（或最小的前置測試子集）跑出失敗；用二分法找出**汙染它的前置測試**（猜測是改了 `EMBEDDING_*`／`VECTOR_DIM` 環境變數或 `core.config` 模組狀態而未還原）。
2. 判斷**誰該改**：若是前置測試汙染 → 修該測試（用 `monkeypatch`，自動還原）；若是被測測試對全域狀態太脆弱 → 改被測測試為顯式隔離環境。**不改 production 預設值**。
3. 驗證：全量 pytest 無此失敗；`-p no:randomly`（若有）與不同順序各跑一次；新增或調整的測試**先用刻意破壞驗證會失敗**（比照過往做法）。
**驗收**：全量 **≥1578 passed、0 failed**（1577＋原失敗項）；根因寫成一段（哪個測試、改了什麼狀態、為何沒還原）；`git diff` 只動 `tests/`。
**禁止**：不改 `core/` 或任何 production 程式；不用 `skip`／`xfail` 掩蓋；不調整其他測試的斷言。
