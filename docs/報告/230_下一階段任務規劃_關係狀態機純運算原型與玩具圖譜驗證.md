## 2. S1 規格

**位置**：新增純 Python 模組（建議 `services/relation_lifecycle.py`，位置由執行者依專案架構與節點卡規範決定並說明理由）。**純運算、無 I/O**；匯入只允許標準庫（`dataclasses`／`enum`／`typing`／`collections`／`re` 等）；**不匯入** `neo4j`／`core.config`／`routers`／其他 `services` 重量模組；匯入不改 `os.environ`（有測試）。

**狀態（暫定，列常數並標 `PROVISIONAL`）**：`候選`（第一個狀態）、`有效`、`已被取代`、`已終止`、`爭議`、`已駁回`。

**事件（暫定）**：以「事件」驅動，**時間只是事件的選用屬性**。至少：`抽取完成`（建立，進入候選）、`驗證通過`、`驗證不通過`、`偵測到矛盾`、`裁決保留`、`裁決以他條為準`、`新版取代`（修法生效／新版出現）、`終止`（廢止／關係結束）、`重新生效`。每個事件為**不可變**資料（例如 `@dataclass(frozen=True)`），帶：事件型別、可選 `effective_date`（可為空——**沒有日期也必須能正常轉換**）、可選 `reason`、可選 `evidence_ref`、可選 `trigger_kind`（時間／事件／偵測／人工，僅記錄用）。

**允許轉換（以報告229 §3 為準）**：候選→有效（驗證通過）／候選→已駁回；有效→爭議（偵測矛盾）／有效→已被取代（新版取代）／有效→已終止（終止）；爭議→有效（裁決保留）／爭議→已被取代（裁決以他條為準）；已終止→有效（重新生效＝結束後重新開始）。**終點狀態**：`已被取代`、`已駁回`（不得有任何轉出）。其餘轉換一律非法。

**核心函式（至少）**：
1. `apply_event(state, event) → 結果`：純函式；非法轉換**回傳含明確原因的結果物件（不丟例外）**，不修改輸入；
2. `replay(events, initial=None) → 結果`：**狀態是事件重播的投影**（Round 3 原則）；回傳最終狀態、完整轉換紀錄（逐步：前狀態、事件、後狀態、是否合法）、第一個非法事件（若有）；重播**決定性**（同樣事件序列必得同樣結果）；
3. **互斥檢查** `check_exclusivity(實例集合)`：給定多個關係實例（每個含鍵〔主詞,關係型別,受詞〕與其當前狀態），**同一鍵同一時刻最多一個「有效」**，回傳違規清單；
4. **Q1 擴充機制**：以參數（例如 `LifecycleSpec`／擴充表）允許個別關係型別追加「額外狀態與轉換」，但**核心不變量不可被擴充破壞**：終點狀態不得被加入轉出、核心轉換不得被刪除或改道；違規擴充要明確報錯（回傳驗證結果）。附一個**虛構關係型別**的擴充範例與測試。
5. 狀態與事件序列的可讀說明函式（例如 `explain(history)` 產出中文轉換日誌），供示範使用。

**不得**：提供任何「修改既有事件」的 API（更正以**追加事件**表達，不覆寫、不刪除；本階段不必實作 CORRECTION，但不得提供就地修改）；寫入檔案；依賴時間函式（如 `datetime.now()`）；提供儲存或序列化到資料庫的程式。

**測試（必須）**：每個狀態、每個事件、**每一條允許轉換與每一類非法轉換**、終點狀態不可轉出、重播決定性（同序列多次同結果）、**沒有日期的事件也能轉換**、有日期與無日期的事件結果一致（時間不影響轉換合法性）、互斥檢查（零違規／一違規／多鍵）、擴充機制（合法擴充、破壞核心的擴充被拒）、不可變性（嘗試修改事件應失敗）、匯入不改 `os.environ`。

## 3. S2 規格（玩具圖譜驗證）

新增示範腳本（放 `scripts/analysis/`，**只用腳本內寫死的虛構資料**，不連 DB、不讀任何真實資料檔），約 **10 條虛構關係**（以通用、非真實法規的虛構句子即可，例如「甲公司／應給／乙福利」），涵蓋：
1. 正常生命週期：候選→有效；
2. **修法取代**：有效→已被取代，且**新版**走自己的候選→有效，互斥檢查通過；
3. **終止後重新生效**（結束後重新開始，驗證舊做法併成一條無法表示的案例）；
4. **爭議**：偵測矛盾→裁決保留；另一條裁決以他條為準；
5. **候選被駁回**；
6. **非法轉換被拒**（如已被取代→有效、已駁回→有效）；
7. **互斥違規被偵測**（同鍵兩個有效）；
8. **無日期事件**與**有日期事件**並存；
9. 擴充範例：某虛構關係型別追加一個額外狀態並運作；
10. 重播決定性。

輸出：可讀的中文示範報告（Markdown）與 JSON；測試以斷言鎖定示範結果。**報告必須註明全部為虛構玩具資料，不代表任何真實法規或 KG#4。**
