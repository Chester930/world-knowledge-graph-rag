## 2. 方法與限制

- 成員清單依節點卡登記；`svo_service.py` 中「輔助」的界線（`_kg_fact_label`、`_fact_*_index_name` 是否算 N9）是**人工判斷**，可在腳本頂部 `MEMBERS` 調整。
- 相依、import、設定讀取、副作用由 AST 抽出；動態存取抓不到。Neo4j 執行點只計 `execute_query／execute_read／execute_write` 呼叫。
- 外部呼叫者：AST（from-import、模組屬性、patch 字串）＋純文字 grep 交叉（§5）。**本任務沒有啟動 Neo4j、Ollama 或任何抽取／檢索**。

## 8. 隱性耦合

1. **查詢路徑內的 DDL 寫入**（§1）：`vector_search_facts` 惰性建立 Fact 向量索引（每次查詢都會執行一次 `CREATE VECTOR INDEX IF NOT EXISTS`，維度取 `len(query_vector)`），hybrid 時另於 try 區塊內建全文索引（`:1570`）。含義：① 搬移 `vector_search_facts` 不能只當「純讀取」；② 與 `GraphSchemaPort`（P-A）有相依；③ **對 KG 唯讀的環境（唯讀帳號）會失敗**（未實測）。
2. **索引／標籤命名輔助共用**（G4）：per-KG 標籤 `Fact_<kg>`（`_kg_fact_label`）同時支撐檢索、索引建立、Fact 寫入（N5）。
3. **賦值式 monkeypatch**（§5）：3 個根目錄腳本以賦值替換 `routers.agent.vector_search_facts`。
4. **golden test 錨點常數**（§6）：`agent._SEED_*`、`_BFS_PER_SEED_LIMIT`、`_DOC_SCOPE_TOP_N_FACTS`、`svo._BFS_*`。
5. **`chat()` 計時與短路不變量**（§4）。
6. **N9→N4 的匯入**（G6）與 **N9→P-A 的匯入**（G4）：搬移後會形成跨節點相依，目錄／介面歸屬未定。
7. 模組載入時編譯的常數：**N9 成員沒有**（無 `lru_cache`、無預編譯 regex；不同於 N4）。
