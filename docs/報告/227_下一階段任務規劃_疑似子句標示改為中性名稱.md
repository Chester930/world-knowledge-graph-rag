# 報告227：下一階段任務規劃——「疑似子句」標示改為中性名稱（只改名稱，不改規則）

> **日期**：2026-10-01
> **性質**：小型任務規劃。分工同前：**規劃對話決定、執行者執行、規劃對話只記錄**。**本文件只由規劃對話修改（§6 執行紀錄）。**
> **依據**：使用者「同意建議，先處理疑似子句改名」。理由見[報告226](226_疑難標註項雙獨立盲測複核結果.md) §5c：`mark_entity_name_shape()` 是**字面規則（長度≥12＋條文用語）**，其「強候選」占 ≥12 字名稱的 89%，但 O2 盲測複核（含使用者確認）顯示真正含謂語的子句只有 **54%**（名詞片語 44%、專有名詞 2%），叫「疑似子句」會誤導。
> **基準**：全量 pytest **1723 passed／0 failed**。
> **本任務只改名稱，不改規則**：長度門檻、特徵關鍵字、判定邏輯、回傳分級（兩級）、trace 鍵名（`subject_name_shape`／`object_name_shape`）、旗標行為**全部不變**。不連 Neo4j、不啟動 Ollama、不改 routers／core／prompt／排序。
