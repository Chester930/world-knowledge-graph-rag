**已經真的能動的部分**：

1. **`repositories/kg_repo.py`／`services/knowledge_graph_service.py` 完全是 `NotImplementedError` 空殼**——每一個「把文件分配進某個 KG」的 API 端點（`routers/staging.py` 的 `classify`／`assign`／`cluster/confirm`）都依賴 `KGRepository`，現在呼叫下去會直接 500。這是**比 Worker 迴圈更前面**的卡點：文件連進哪個 KG 都定不了。
