**驗收（沿用 P2 的獨立驗收方法，並加入 N4 特有項目）**：

- **AST 逐字比對**：搬移的每個函式與常數，內容與搬移前逐字相同（允許差異僅限 import 行、路徑常數修正及其直接相關行，且逐項列出）。
- **`svo_service.py` diff 形狀**：只有刪除被搬移的定義、新增匯入區塊。
- **重新匯出身分測試**：舊名稱 `is` 新模組的同一物件（對所有被外部使用或被補丁的名稱）。
- **差分行為測試**（舊實作 vs 新模組，≥1000 組，使用**假 LLM／假 embedding provider**，不連網路）：輸出 `==`；**例外型別與訊息相同**；**副作用呼叫序列相同**（`add_candidate`、`log_escalation` 的呼叫次數、順序與參數）。期望值必須**先用搬移前的實作取得**。
