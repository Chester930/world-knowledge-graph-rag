## 3. 檢定力表（公式與假設）

**方法（可重算）**：對 N 題、兩臂各一次通過／未通過，逐題配對；只有「不一致對」（一臂過、一臂不過）提供資訊。設不一致對共 n 對，其中「新臂勝」w 對。**精確 McNemar＝二項符號檢定（H0：勝率 0.5），雙尾** `p = min(1, 2·Σ_{i≥max(w,n−w)}^{n} C(n,i)/2^n)`，α=0.05。

**驗證規劃對話已算的三個值（均重算吻合）**：6:0→p=0.0312（≈0.031）、8:1（n=9）→0.0391（≈0.039）、10:2（n=12）→0.0386（≈0.039）。
