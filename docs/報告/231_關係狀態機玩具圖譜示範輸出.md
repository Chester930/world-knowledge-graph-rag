## 情境 7：非法轉換被拒

已被取代→有效、已駁回→有效、尚未建立就驗證，皆被拒；狀態維持，重播繼續。

**實例 S7-a**　鍵：（寅單位／需要／卯文件）　生命週期：核心　最終狀態：**已被取代**

```
第1步 ✓ （無） —[抽取完成]→ 候選　（日期：未提供）
第2步 ✓ 候選 —[驗證通過]→ 有效　（日期：未提供）
第3步 ✓ 有效 —[新版取代]→ 已被取代　（日期：未提供）
第4步 ✗ 事件「重新生效」被拒，狀態維持「已被取代」：「已被取代」是終點狀態，不得有任何轉出（收到事件「重新生效」；需要新的關係實例重新走候選→有效）　（日期：未提供；原因：企圖讓已被取代者復活）
第5步 ✗ 事件「驗證通過」被拒，狀態維持「已被取代」：「已被取代」是終點狀態，不得有任何轉出（收到事件「驗證通過」；需要新的關係實例重新走候選→有效）　（日期：未提供）
最終狀態：已被取代
```

**實例 S7-b**　鍵：（辰單位／需要／巳文件）　生命週期：核心　最終狀態：**已駁回**

```
第1步 ✓ （無） —[抽取完成]→ 候選　（日期：未提供）
第2步 ✓ 候選 —[驗證不通過]→ 已駁回　（日期：未提供）
第3步 ✗ 事件「驗證通過」被拒，狀態維持「已駁回」：「已駁回」是終點狀態，不得有任何轉出（收到事件「驗證通過」；需要新的關係實例重新走候選→有效）　（日期：未提供；原因：企圖讓已駁回者通過）

```

**實例 S7-c**　鍵：（午單位／需要／未文件）　生命週期：核心　最終狀態：**（尚未建立）**

## 情境 10：擴充範例：虛構關係型別追加「暫停」狀態

**實例 S10-a**　鍵：（虛構子公司／虛構-暫停適用／虛構方案）　生命週期：虛構-暫停適用　最終狀態：**已終止**

```
第1步 ✓ （無） —[抽取完成]→ 候選　（日期：未提供）
第2步 ✓ 候選 —[驗證通過]→ 有效　（日期：未提供）
第3步 ✓ 有效 —[暫停適用]→ 暫停　（日期：2021-01-01）
```

## 擴充檢查（Q1：通用核心＋可個別擴充）

- 虛構擴充「虛構-暫停適用」：通過驗證。

- 破壞核心的擴充「終點狀態加轉出」：被拒——終點狀態「已被取代」不得有任何轉出：已被取代—[復活]→有效
- 破壞核心的擴充「改道核心轉換」：被拒——不得改寫或重述核心轉換：有效—[終止]→已駁回
- 破壞核心的擴充「刪除核心轉換」：被拒——不得刪除核心轉換 有效—[終止]→已終止
