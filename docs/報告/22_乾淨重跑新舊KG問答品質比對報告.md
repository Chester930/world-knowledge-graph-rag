# 22．乾淨重跑新舊KG問答品質比對報告

**日期**：2026-09-01
**背景**：延續 [21_抽取管線稽核與修正報告](21_抽取管線稽核與修正報告.md) 的5項修正，`c15949bf-cf96-46ad-90a2-a8579d7b20b4`（下稱「新KG」）以規則7擴充＋[19_SVO抽取完整性自我核對機制設計報告](19_SVO抽取完整性自我核對機制設計報告.md)＋[20_抽取數值忠實性核對機制設計報告](20_抽取數值忠實性核對機制設計報告.md)＋報告21五項修正對64份文件從頭乾淨重跑；`76bc98ff-2cbd-447e-a087-7f2df6898655`（下稱「舊KG」）是三項修正陸續上線期間累積到49%進度時凍結保留的快照，作為「修正前/中」基準。

本報告驗證：**乾淨重跑後的新KG，在問答品質上是否確實優於舊KG的抽取結果？**

## 1. 測試設計

延續 [18_三管線檢索策略與抽取方法比較報告](18_三管線檢索策略與抽取方法比較報告.md) 的方法論，但因新KG仍在背景持續抽取中（截至測試當下約600/3303，18%），本次**只挑選新舊KG皆已100%完成抽取的文件**出題，避免用未完成範圍的比較失真（此前一輪比較已因範圍不對稱被判定「不準」而暫緩，見報告18附記）。

三個條件：

- **[A]** KG Agent（`use_svo=True`）對新KG `c15949bf`
- **[B]** KG Agent（`use_svo=True`）對舊KG `76bc98ff`（凍結快照）
- **[D]** 純LLM基準（`use_svo=False`，完全不檢索）

題目沿用報告18正式5題與規則7 targeted test的2題中，涉及文件已在兩個KG都100%完成的5題（重用原題文字，確保與先前測試結果可對照）：

| 題號 | 涉及文件 | 涉及修正機制 |
|---|---|---|
| 1 | D0080015_警察人員特別休假辦法（第4條） | 完整性自我核對＋數值忠實性核對（報告19、20核心驗證案例） |
| 2 | N0030006_勞工請假規則（第7條，事假） | 規則7（報告18核心驗證案例） |
| 3 | N0030006_勞工請假規則（第7條，家庭照顧彈性） | 規則7 |
| 4 | N0090051_外國人請假返國辦法 | （對照組，未特別針對某項修正） |
| 5 | F0040034_員工接受召集請假期間薪資費用加成減除辦法 | （對照組） |

**技術備註**：測試直接呼叫 `routers.agent.chat()` 並消費其 `StreamingResponse.body_iterator`，刻意不透過 `main.py` 啟動FastAPI伺服器——`main.py` 的 `lifespan` 會無條件啟動不分 `kg_id` 的全域背景worker（`run_extraction_worker()`），過去已發生過它誤動到理應凍結的舊KG的先例（報告21稽核期間的實際案例）。直接呼叫route handler可完全避免此風險。測試期間另暫停了drain腳本、事後重啟，避免與測試同時搶佔Ollama資源。

## 2. 逐題結果

### 題1｜警察人員特別休假辦法：核發依據、天數、是否與年資有關

- **[A] 新KG**：正確列出「获得特别贡献或特殊功绩受颁勳章者给予**三至七日**之特别休假」與「其他情形给予**一至三日**之特別休假」兩個檔次，誠實標示「資料未明確記載，無法確認…是否與服務年資有關」。
- **[B] 舊KG**：**只列出「一至三日」情形，完全遺漏「三至七日」較高檔次**，最終結論「最高可以给予**三日**特别休假」——與辦法原文（最高七日）不符。
- **[D] 純LLM**：全面捏造，引用不存在的《警察人員特別休假條例》、虛構《勞動基準法》第31-33條與「服勤滿一年5日、滿20年14日」等不存在的規則。

**判定：[A] 明顯優於 [B]**——這正是報告19完整性核對（漏抽取原文中的次要條款）與報告20數值忠實性核對（防止數量憑空捏造/遺漏）要解決的失效模式，新KG正確保留了較高檔次資訊，舊KG漏掉後導致「最高天數」這個關鍵結論性錯誤。[D] 明顯最差，全篇幻覺。

### 題2｜勞工請假規則第7條：事假天數與工資

- **[A]**：「一年內合計不得超過十四日」「請事假期間不給工資」，答對核心數字。
- **[B]**：同樣答對「14天」「不給工資」，且額外補充「應於事前親自以口頭或書面敘明請假理由及日數」。
- **[D]**：迴避具體天數，承認「勞動基準法對此並沒有明確規定」（此題劃錯法規，事假規定在《勞工請假規則》非《勞基法》本文）。

**判定：[A]／[B] 打平**，兩者都答對核心數字。此條文的規則7修正效果在報告18已用專門測試驗證過，本題未再現額外差異，屬預期內結果。

### 題3｜勞工請假規則第7條：家庭照顧彈性

- **[A]**：只答出「可以依第七條規定請事假」，**未提及原文「並得擇定以小時為請假單位」這項關鍵彈性**。
- **[B]**：正確答出「事假期間可選擇**以小時為單位**」。

**判定：[B] 優於 [A]**——本題新KG反而漏掉了原文明確記載的細節。這是本次測試中唯一的負面訊號，值得如實記錄：完整性/數值忠實性核對機制解決的是特定類型的失效模式（次要條款遺漏、數量捏造），不保證涵蓋全部抽取品質問題；BFS種子與路徑選擇（本題[A]僅拿到2句、[B]拿到2句但抓對了關鍵句）在單次抽取中仍有隨機性。

### 題4｜外國人請假返國辦法：返國期日排定權

- **[A]**：「返國期日是由外国人自行排定。雇主不可以片面更改」——簡潔正確。
- **[B]**：BFS三元組=7但接地核對「2句中2句未接地」，最終答「並未明確記載，無法確認」——**完全沒能利用到相關事實**。
- **[D]**：捏造「特別休假日是由雇主與勞工雙方協商確定」，與原文（外國人自行排定）不符。

**判定：[A] 明顯優於 [B]**。

### 題5｜召集請假薪資減除比例

- **[A]**：誠實承認「事實清單中沒有提及有關從所得額中減除的比例」。
- **[B]**：提供了較多背景定義（請假期間定義、應備文件），但同樣承認「沒有提到具體的減除比例，無法確認」。

**判定：打平**（兩者皆未答出具體比例，可能該比例本身不在此條文文字中）。

## 3. 總結

| 題號 | 結果 |
|---|---|
| 1 | 新KG勝（漏檔次問題已修正） |
| 2 | 打平 |
| 3 | **舊KG勝**（新KG漏了一項細節） |
| 4 | 新KG勝 |
| 5 | 打平 |

**5題中：新KG勝2、打平2、舊KG勝1。** 純LLM基準在全部5題中皆是幻覺最嚴重或迴避最多的選項，再次驗證KG-based問答相對純LLM的既有優勢（呼應報告18結論）。

新舊KG的比較呈現**淨正向但非壓倒性**的結果：題1的完整性/數值忠實性核對效果清楚可見（避免了「最高七日」誤答為「最高三日」這種實質性錯誤），但題3顯示這些核對機制不是萬靈丹——單次LLM抽取仍有隨機性，某些細節仍可能在新的一輪抽取中被漏掉而舊版恰好抓到。這與報告19、20設計文件中「不做多輪迭代收斂」「留待第五章消融實驗評估」的誠實侷限一致。

## 4. 誠實侷限

- 樣本數small（5題），統計把握力有限，結論屬方向性觀察而非嚴謹顯著性檢定。
- 測試時新KG僅抽取到約18%（600/3303），受限於「新舊KG皆須100%完成」的篩選條件，只涵蓋了8份小型文件（各6-9個chunk），未涵蓋大型文件（如N0030001_勞動基準法，數十個chunk）——大型文件的抽取品質差異尚待新KG完整跑完後另行驗證。
- 舊KG本身不是純粹的「修正前」快照，而是三項修正陸續上線期間累積的混合快照（見背景說明），题2打平的結果可能反映的是「舊KG累積時規則7已經上線」而非規則7無效——報告18已用更早期的KG（`99a25aca`，規則7修正前）做過乾淨的pre/post比較，此處不重複驗證。
