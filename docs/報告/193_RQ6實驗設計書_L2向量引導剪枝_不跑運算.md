## 5. 統計與檢定力〔事實＋推論〕

- **二元（19 題，W1）**：精確 McNemar（雙尾二項符號檢定，α=0.05），公式與假設同報告179 §3；需不一致對 **12／20／49**（q=0.9／0.8／0.7，檢定力 ≥0.8）。池 19 題在 d=0.5、q=0.9 下檢定力 0.66（報告179 表 2）。**但**依 §2，L2 只影響約 1／19 題 → 不一致對最多 ~1 對，**二元指標在此設計下幾乎無資訊**〔推論〕。
- **連續（配對）**：以每題兩臂差值 Δᵢ 做配對 t 或 Wilcoxon 符號秩（雙尾 α=0.05）。可偵測標準化效應 d_z（＝mean(Δ)/sd(Δ)，檢定力 0.8）：normal 近似 `d_z ≈ (z₀.₉₇₅ + z₀.₈)/√n = 2.80/√n`；**t 分布精確值**（非中心 t，本機純數學計算）：n=6 → **1.44**、n=10 → **1.00**、n=19 → **0.68**、n=42 → **0.44**（normal 近似分別 1.14／0.89／0.64／0.43；小 n 時 normal 低估）。Wilcoxon 在 n=3 時兩尾最小 p＝0.25、n=5 時 0.0625，**需 n≥6 個非零差值才有可能 p<0.05**（n=6 時最小 p＝0.031）。
- **有效 n 的關鍵**：連續指標只有在「兩臂檢索結果不同」的題才有非零 Δ；依 §2，方案 A 下有效 n≈3（`<8` 的題數）→ **任何檢定都無法達顯著**；方案 B 的有效 n〔無資料〕，須由 Phase 0 決定（§7）。**差值標準差 sd(Δ)〔無資料〕**，因此「d_z 對應的原始單位效應」無法換算。

## 6. 替代設計 A／B／C 與採用規則

> 三案**不替使用者選**；各寫成本、外部效度、風險。

### 方案 A：維持現行門檻（`svo_hops=2`、`expand_when_below=8`），只做描述

- 做法：兩臂皆 `svo_hops=2`；基準臂＝無 L2、L2 臂＝`k∈{5,10,20}`；W2（檢索層級）即可。
- **預期**〔推論〕：約 3／42 題有差異，其餘逐位元相同 → **近零效應**；只能做描述（哪幾題、候選池如何變、gold 是否保持）。
- 成本：低（W2、無生成）；外部效度：檢索層級中、答案層級無；風險：結論多半是「現行題庫下不可測」，需在論文誠實呈現（§8）。

### 方案 B：提高 `expand_when_below`（改變基準）

- 做法：把門檻調高（例如使多數題進擴展分支；**取值〔無資料〕**，須由 Phase 0 的 1-hop 分布＋候選邊數決定，現有資料只知 1-hop 的 median 為 18、max 63）。兩臂（hops=2，基準＝無差別 `2..hops` 擴展、L2 臂＝prize）都需**重跑基準臂**；與凍結 S0 不可比。
- **風險**：基準臂的無差別 2-hop 擴展會組合爆炸——`models/document.py:63-64` 引報告26 §4 #4：Q5／Q6／Q7 各 330–440 秒；論文 `03:857` 引報告22／23 單次回傳 800 筆的極端案例（皆為歷史觀察，**非本次量測**）；在 8GB VRAM、記憶體吃緊的環境下重跑生成有被中止風險（§7）。
- 成本：高（W1 才有答案層級；W2 檢索層級仍低）；外部效度：改變基準後，是「另一個系統配置」的比較；優點：有機會產生有效 n。

### 方案 C：不做 RQ6，把 prize 當離線檢索品質分析

- 做法：不經 `chat()` 觸發條件，直接以 W2 對全部 42 題的 1-hop frontier 計算 prize 分數（等同「如果有擴展，prize 會挑哪些」），分析 prize 排序對 gold 片段的排名／召回（離線、純檢索層級）。
- 成本：低；外部效度：**不是 RQ6 的消融**（沒有 end-to-end 比較），只能作為機制分析／附錄；風險：易被誤讀為 RQ6 結果，論文須明寫定位。

### 採用規則（跑前凍結）〔提案；X、Y 與理由，供使用者拍板〕

**原則（明寫）：未過規則＝不採用；規則在 Phase 0 結束、Phase 1 開始前凍結，之後不得更換指標、門檻或題集。**

| 規則 | 建議值 | 理由與依據 |
| --- | --- | --- |
| **G0（可測性門）** | Phase 0 量到「兩臂 post-cap prompt 行不同」的題數 **≥ 10／42** 才進 Phase 1；否則結論＝「現行題庫與基準下 RQ6 不可測，不採用」 | Wilcoxon 兩尾 α=0.05 至少需 6 個非零差值（§5）；取 10 留餘裕且 t 分布下 d_z 需 1.00（§5）。**10 是提案，不是文獻值** |

## 8. 風險與回退〔提案〕

- **接線改變預設行為的偵測**：預設關時傳給 `bfs_query` 的參數與現行逐位元相同；沿用差分 golden（K 臂快照比對腳本 `scripts/analysis/compare_p2_snapshots.py` 的做法）＋全量回歸以 **1582 passed** 為基準；刻意破壞（預設改開）golden 必須失敗。
- **L2 的 embedding 呼叫失敗時的降級**：現行程式碼三參數缺任一就走原無差別擴展（`svo_service.py:2786-2790` 的 `l2_active` 條件）；但**若 `encode_batch` 在 L2 分支內拋例外**（`:2819`），沒有 try/except，會中止整個 `bfs_query` ——〔事實〕（讀碼，未執行）；接線時需決定是「失敗退回無差別擴展」還是「失敗讓請求失敗」（〔提案〕：前者，並記入 trace）。
- **結果可能是「準確率無差異」**：論文定位＝診斷 KG 何時有增益（記憶「文獻／專案證據查證（報告61）」）；RQ6 若呈現近零效應，應如實寫成「在現行基準下 L2 不觸發／僅影響少數題；剪枝機制已實作但未能在現有題庫顯示效益」，並把「基準必須改變才有可測效應」列為限制與未來工作——**不調整規則、不更換指標以求得顯著**。
- **與 RQ1 凍結的相容性**：W1 的基準臂（hops=2）不等於凍結 S0（hops=1），**不得與 S0–S3 混比**；RQ6 結果單獨呈現。
